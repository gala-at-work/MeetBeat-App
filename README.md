# Meet-Beat-App
Project Meet-Beat, lets you make most out of networking events

Meet-Beat is a mobile-first networking prototype that helps event attendees identify the most relevant people in the room. It turns each user’s goals, skills, interests, and offers into a “Networking DNA,” then ranks attendees using explainable, goal-based matching. The product includes event-specific onboarding, a visual match radar, detailed match reasoning, personalised conversation starters, messaging, and connection tracking—demonstrating end-to-end product thinking from user problem and prioritisation to interaction design and prototype execution.

### What I did

* Identified the core user problem: networking events create many introductions, but few genuinely relevant connections.
* Defined the product vision, target users and key business use cases for attendees and event organisers.
* Translated the idea into a complete end-to-end user journey, from onboarding to post-event follow-up.
* Designed the product architecture, including:
  * Networking DNA
  * Event-specific check-in
  * Goal-based attendee matching
  * Matching algorithm
  * Personalised conversation starters
  * Messaging and connection tracking
* Defined the matching logic, feature priorities, user inputs, profile fields and event-specific signals.
* Planned every screen, interaction, navigation path and information hierarchy.
* Developed the overall UI/UX strategy, including layout, visual hierarchy, usability and mobile-first behaviour.
* Considered edge cases such as missing data, unsupported voice input, incomplete onboarding and local demo mode.
* Prioritised features around the main user outcome rather than adding unnecessary functionality.
* Created the full product specification and iterated on the prototype based on usability and product clarity.
