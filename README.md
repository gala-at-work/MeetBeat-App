The App: 
The core user problem: networking events create many introductions, but finding relevant connections is mostly guesswork, the app attempts to optimise it.

### What I did
* Defined the product vision, target users and key business use cases for attendees and event organisers.
* Translated the idea into a complete end-to-end user journey, from onboarding to post-event follow-up.
* Planned every screen, interaction, navigation path and information hierarchy.
* Designed the product architecture, including:
  * Defined Frontend & Backend Features and algorithm including:
  * Networking DNA
  * Event-specific check-ins
  * User Matching algorithm
  * Personalised conversation starters
  * Messaging and connection tracking
* Defined the matching logic, feature priorities, user inputs, profile fields and event-specific signals.
* Developed the overall UI/UX strategy, including layout, visual hierarchy, usability and mobile-first behaviour.
* Considered edge cases such as missing data, unsupported voice input, incomplete onboarding and local demo mode.
* Prioritised features around the main user outcome rather than adding unnecessary functionality.
* Created the product specification and iterated on the prototype based on usability and product clarity.

*This App was built using a vibe-coding App
